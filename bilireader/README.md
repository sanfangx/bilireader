# bilireader

BiliReader 的 Flutter App 原始碼。

完整專案介紹、截圖與目錄說明請看 [../README.md](../README.md)。

## 開發

```bash
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter run
```

## 檢查

```bash
flutter analyze
flutter test
```
